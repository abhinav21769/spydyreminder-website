Easy Installation Guide

Quick setup for Mac and Windows

🪟 Windows Setup

If Windows SmartScreen Appears

Click More info on the blue screen, then click Run anyway. Spydy will open right in your Taskbar!

🍎 macOS Setup

If Mac Gatekeeper Appears

Open System Settings > Privacy & Security, scroll down and click Open Anyway (or Right-Click > Open).
